# Climate models underestimate long-term changes in the precipitation intensity distribution compared to station observations
Replication code for "Climate models underestimate long-term changes in the precipitation intensity distribution compared to station observations" by Jingya Han and Angeline G. Pendergrass.

The repository contains the following folders:
* `data_process/`, which contains 'matlab' script and functions to perfrom the analysis from the initial `.dly` files to the netCDF files used for plotting. The workflow follows the order of: run_00, run_01, run_02, run_03, run_04. All other .m files are functions that needed for calculation. The subfolder `dly/` contains the original GHCNd daily precipitation data for the stations used in this study. The subfolder `ghcnd_pr/` contains quality-controlled daily precipitation data. The subfolder `tas/` contains observed global annual temperature datasets used in this study. The original cmip6 data are not included in this repo. Users can download the cmip6 data from: https://aims2.llnl.gov/search
* `dataforplot/`, where the final data used to create the figures is stored. The format of the data is netCDF. The smoothed precipitation amount distribtuions and the increase and shift modes aggregated over stations are stored in file "way1_stations_20%miss_19551984_19942023.nc". The smoothed precipitation amount distribtuions and the increase and shift modes aggregated over co-located grids in CMIP6 models are stored in file "way1_MMM_20%miss_19551984_19942023.nc". Intermediate processed data is not stored in this repo due to its large size, but feel free to contact me to organize a data transfer. <!--The smoothed precipitation amount distributions with uncertainty estimates for stations and for co-located grid points in CMIP6 models are available at (insert doi!!!!).-->
* `figures/`, where .pdf and .png outputs for the main figures from the scripts are stored.
* `scripts/`, which contains the ` matlab ` code used to generate the figures.
* `update_modes_each_year/`, which contains updated figure 1 and figure 2 with data in 2024.
